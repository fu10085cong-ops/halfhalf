# HalfHalf 标准输入格式(FORMAT.md)

> **这是排版输入 Markdown 的唯一权威契约。**
> 三个消费方必须与本文对齐:结构化提示词(`packages/server/src/engine/ai-structurize.ts`
> 的 `STRUCTURIZE_SYSTEM_PROMPT`)、结构体检(`checkStructure`)、切块器
> (`chunk-markdown.ts`)。**改格式先改这份文档,再同步三处代码。**

## 0. 设计目标

排版引擎把 Markdown 切成"块"(block)后测量、拼装。块是**排版原子**:不可拆、
不可跨页。格式规范的每一条都为了让 AI 产出的文档天然就是健康的块粒度、
可预测的渲染结果——排版质量的上限在输入侧就定了。

## 1. 结构与粒度

- 一个 `#` 总标题,若干 `##` 分节,可用 `###`(直至 `######`)细分。
- **`##` 节 = 排版原子**。每节正文 ≤800 字(`chunkMarkdown` 的 `maxBlockChars`);
  内容多就多分节。超过 1600 字且无法按更深标题细分的节是"巨型块",
  会把全文字号钉死在"最大块塞进一页"的下限——体检会拦。
- 标题一律 ATX(`#` 井号)。禁止 setext(文字下面画 `---`/`===`)。
- 独立成行的图片 `![alt](src)` 自成图片块;图片后的文字进"续块"。

## 2. 元素封闭子集(白名单以外 = 禁止)

| 允许 | 说明 |
|---|---|
| ATX 标题 `#`–`######` | 结构骨架 |
| 段落 | — |
| 有序/无序列表 | **嵌套最多两层**,再深排版密度崩 |
| 粗体/斜体 | — |
| 行内代码 `` ` `` | — |
| 围栏代码 ```` ``` ````(标语言) | 围栏内的一切按代码原样对待 |
| GFM 管道表 | 见 §4 |
| LaTeX 公式 `$...$` / `$$...$$` | 见 §3 |
| 独立成行的图片 | 含 data URI;见 §6 方言 |
| 引用块 `>` | **仅限提示/警示行**(如检索产物的"非教材口径"横幅),不用于正文 |

| 禁止 | 原因 |
|---|---|
| 超链接 `[文字](url)`、`<url>` | 纸上点不开,纯占版面。**去掉链接语法只保留文字** |
| 分隔线 `---`/`***`/`___` | 无信息量;`---` 还与 setext/伪表格混淆 |
| 内联 HTML(`<br>`、`<b>`、`<sub>` 等) | 渲染链路不保证支持;上下标走 LaTeX |
| Unicode 上下标字符(`x²`、`H₂O`) | KaTeX 管不着、字体覆盖不稳,公式一律 LaTeX |
| 脚注、任务列表、删除线 | 排版未定义行为 |

## 3. 公式

- 行内 `$...$`,独立成行 `$$...$$`,必须能过 KaTeX(体检有预检)。
- 禁止用 Unicode 上下标、希腊字母拼装"看起来像公式"的文本。

## 4. 表格

- 一律 GFM 管道表(`| 列 | 列 |`,第二行 `|---|---|`)。
- Word/Pandoc 转换产物里"空格对齐 + 虚线行"的伪表格、"名称␣␣含义"键值行,
  **必须**转成管道表(真实事故:db-systems 判例 20+ 张表全塌成一团文字)。
- 长表格拆分规则**暂缺**:表格也是排版原子,超高会被截断(排版后有警告)。
  拆分阈值等积累足够真实范例后再定,不臆想(2026-07-28 用户裁决)。

## 5. 保真红线

结构化**只重组,不新增、不压缩**:原文的公式、数字、定义、结论一个不丢不改;
只删与知识无关的噪音(页眉页脚、"如下图所示"、乱码、重复)。语义压缩是
①精简(`ai-compress`)的职责,两步不许合并——否则安全网分不清"调结构"与"丢内容"。

## 6. 内部方言(系统生成,人手不写)

- **`![HH_SOURCE_PAGE_n](...)`**:PDF 保真页兜底图。切块器对它特殊处理——
  与所在标题绑成一个原子,不单独拆块。
- **data URI 图片**:用户贴图/截图落地形态,整行 `![名称](data:image/...)`。
- **HTML 注释 `<!-- -->`**:引擎全链路无视(切块前剥除),可用作给人看的元数据;
  不算正文、不进字数。

## 7. 豁免与入口

所有文本材料必须经指定提示词(structurize)产出本格式(统一输入闸,
见 `docs/superpowers/specs/2026-07-28-unified-input-gate-design.md`)。豁免:

- **图片材料**:本身就是 §6 的图行,直接可用。
- **保真页文档**(含 `HH_SOURCE_PAGE` 页图的扫描/混合 PDF):内容本体是图,
  与图片同一口径豁免——巨型 base64 进 AI 提示词是 token 灾难,且转换会毁掉
  页图与严格源序(2026-07-28 补,消融 monotonicOrder 挂账时发现的闸缺口)。
- **联网检索产物**:由检索自己的锁格式提示词产出(分节 + 引用块横幅),视为达标。
- **开发 fixture**:手工整理的标准格式样张。

## 8. 已知边界(挂账)

- 多份材料拼接后是多 `#` 文档(每份一个总标题)。切块器能处理;
  是否"降级各份 H1、统一总标题"待排版引擎调优时一并评估。
- 长表格拆分阈值(见 §4)。
