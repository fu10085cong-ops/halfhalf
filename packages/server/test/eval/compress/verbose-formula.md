# 概率论常用分布

## 二项分布

如果一个随机变量 $X$ 服从参数为 $n$ 和 $p$ 的二项分布,那么我们就把它记作 $X \sim B(n,p)$。这个分布所描述的实际含义是,在总共进行 $n$ 次相互独立的伯努利试验的情况下,最终成功的次数所服从的概率分布规律。它的概率质量函数的具体表达式可以写成如下的形式:

$$P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$$

关于这个分布的数字特征,它的数学期望的计算公式是 $E(X) = np$,而它的方差的计算公式则是 $D(X) = np(1-p)$。

## 泊松分布

泊松分布通常被用来描述在某一个固定的时间段之内,某种随机事件所发生的次数所服从的分布规律。如果随机变量 $X$ 服从参数为 $\lambda$ 的泊松分布,我们通常将其记为 $X \sim P(\lambda)$。这个分布的概率质量函数可以表示为下面的式子:

$$P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$$

对于泊松分布而言,有一个非常值得注意的重要特点,那就是它的数学期望和它的方差在数值上是完全相等的,两者都等于参数 $\lambda$ 本身,即 $E(X) = D(X) = \lambda$。
