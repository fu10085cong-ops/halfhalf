# 操作系统进程管理

## 进程与线程的区别

进程是操作系统进行资源分配的基本单位,而线程则是操作系统进行调度的基本单位。需要特别注意的是,一个进程当中可以包含有多个线程,并且这些线程之间是共享该进程所拥有的地址空间的。由于线程之间共享地址空间,因此线程之间的切换开销要明显小于进程之间的切换开销。进程之间的通信必须要借助于操作系统提供的专门的 IPC 机制才能够完成,而同一个进程内部的线程之间则可以直接通过读写共享变量的方式来进行通信。

## 死锁的四个必要条件

死锁的产生需要同时满足四个必要条件。第一个条件是互斥条件,指的是资源在同一时刻只能够被一个进程所占用。第二个条件是占有并等待条件,指的是进程在已经持有了至少一个资源的情况下,又去申请其他的资源。第三个条件是不可剥夺条件,指的是进程已经获得的资源在使用完毕之前不能够被其他进程强行夺走。第四个条件是循环等待条件,指的是若干个进程之间形成了一种首尾相接的循环等待资源的关系。只要破坏掉这四个条件当中的任意一个,就可以有效地预防死锁的发生。
