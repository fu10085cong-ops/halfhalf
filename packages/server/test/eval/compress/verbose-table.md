# 计算机网络分层模型

## OSI 七层模型概览

OSI 参考模型总共划分成了七个不同的层次,下面这张表格对每一层的核心功能以及所对应的典型协议做了一个比较完整的归纳整理:

| 层次 | 功能 | 典型协议 |
|---|---|---|
| 应用层 | 面向用户的网络服务 | HTTP、FTP、SMTP |
| 传输层 | 端到端可靠传输 | TCP、UDP |
| 网络层 | 寻址与路由 | IP、ICMP |
| 数据链路层 | 相邻节点成帧与差错控制 | 以太网、PPP |

## 关于分层的意义

之所以要把整个网络体系结构划分成这样一个一个的层次,其背后的根本原因在于分层这种做法能够带来非常显著的好处。首先,分层使得每一个层次都只需要专注于完成自己那一部分的功能就可以了,而不需要去关心其他层次内部究竟是如何实现的。其次,当某一个层次的具体实现技术发生了变化的时候,只要它对外提供的接口保持不变,那么其他的层次就完全不会受到任何影响。最后,分层的做法也使得整个复杂系统的设计、实现以及后期的维护和排查故障都变得更加容易操作。
