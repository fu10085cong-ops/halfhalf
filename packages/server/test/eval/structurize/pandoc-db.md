事务的 ACID 特性:原子性 Atomicity、一致性 Consistency、隔离性 Isolation、持久性 Durability。

隔离级别由低到高:读未提交 Read Uncommitted、读已提交 Read Committed、可重复读 Repeatable Read、串行化 Serializable。级别越高并发度越低。

脏读:读到别的事务未提交的数据。不可重复读:同一事务内两次读同一行结果不同。幻读:两次范围查询结果集行数不同。

读未提交会有脏读、不可重复读、幻读三种问题。读已提交解决脏读。可重复读解决脏读和不可重复读。串行化全部解决。

索引:B+ 树索引的高度通常是 3 到 4 层。聚簇索引的叶子节点存放整行数据,二级索引的叶子节点存放主键值,所以二级索引查询可能需要回表。

SQL 查询顺序:FROM -> WHERE -> GROUP BY -> HAVING -> SELECT -> ORDER BY -> LIMIT
