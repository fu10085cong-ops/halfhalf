微观经济学期末复习提纲            第 3 周整理     P.1

需求定律:价格上升需求量下降,其他条件不变。需求曲线向右下方倾斜。注意区分"需求量的变动"(沿曲线移动,由本商品价格引起)和"需求的变动"(整条曲线移动,由收入、偏好、相关商品价格引起)。

弹性部分很重要。需求价格弹性 Ed = (ΔQ/Q)/(ΔP/P)。|Ed|>1 富有弹性,降价增收;|Ed|<1 缺乏弹性,提价增收;|Ed|=1 单位弹性,收益不变。生活必需品缺乏弹性,奢侈品富有弹性。如下图所示。

成本概念对照
概念            含义
机会成本        放弃的最大代价
显性成本        实际支出
隐性成本        自有要素的机会成本
经济利润        收益-显性-隐性成本

短期生产:边际报酬递减规律,MP 先升后降。TP 最大时 MP=0。AP 最大时 AP=MP。

计算题常考:已知 Q=100-2P,求 P=20 时的点弹性。Ed = dQ/dP × P/Q = -2 × 20/60 = -0.67,缺乏弹性。
