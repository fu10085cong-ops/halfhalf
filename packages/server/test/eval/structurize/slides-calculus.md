一阶线性微分方程

标准形式 y' + P(x)y = Q(x)

通解公式:y = e^(-∫P(x)dx) [ ∫ Q(x)e^(∫P(x)dx) dx + C ]

当 Q(x)=0 时称齐次方程,通解 y = Ce^(-∫P(x)dx)

可分离变量方程
形如 dy/dx = f(x)g(y),分离后 dy/g(y) = f(x)dx,两边积分即可

二阶常系数齐次线性方程 y'' + py' + qy = 0
特征方程 r² + pr + q = 0
判别式 Δ = p² - 4q

Δ>0 两个不等实根 r₁ r₂,通解 y = C₁e^(r₁x) + C₂e^(r₂x)
Δ=0 二重根 r,通解 y = (C₁ + C₂x)e^(rx)
Δ<0 共轭复根 α±βi,通解 y = e^(αx)(C₁cosβx + C₂sinβx)

例题:求 y'' - 5y' + 6y = 0 的通解
特征方程 r² - 5r + 6 = 0,得 r₁=2, r₂=3
所以通解 y = C₁e^(2x) + C₂e^(3x)
