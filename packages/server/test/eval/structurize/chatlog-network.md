今天问了老师几个网络的问题,记一下哈

我: 老师 TCP 和 UDP 到底啥区别啊
老师: TCP 面向连接,要三次握手,可靠传输有确认重传排序;UDP 无连接,尽力交付,不保证到达
我: 那头部呢
老师: TCP 头部 20~60 字节,UDP 只有 8 字节
我: 哦哦懂了

然后又问了握手
老师说三次握手是 SYN -> SYN+ACK -> ACK,四次挥手比三次握手多一次,是因为被动方还有数据要发,所以 FIN 和 ACK 要分开发

还问了端口
常用的:HTTP 80,HTTPS 443,SSH 22,DNS 53,MySQL 3306
老师说这些必背

最后问了状态码
2xx 成功比如 200 OK
3xx 重定向 301 是永久 302 是临时
4xx 客户端错 404 找不到 403 禁止
5xx 服务端错 500 内部错误
